# KICKO TrimOut Privacy

Last updated: July 15, 2026.

## Local Editing

TrimOut opens, previews, cuts, catalogs, and exports media on the user's computer. Original game videos and local TrimOut projects are not uploaded merely because they were opened or edited. TrimOut does not require an account or license key for local editing and does not include advertising analytics.

Project files can contain local file paths, player name, selected position, clip labels, clip order, and cut times. Users should treat project files as private because they describe local media and player activity.

## Optional KICKO Transfer

The user must explicitly choose to continue in KICKO and approve the connection in a browser. Before upload, the KICKO server verifies the signed-in account and active subscription. If eligibility is not confirmed, no upload grant, cloud media, or KICKO project is created.

When the user approves a transfer, TrimOut sends only the selected exported clips and the information needed to preserve the project: project title, optional player name, optional Scout position, clip file metadata, action categories, ratings, and selected order. Original full-game videos remain on the computer.

Uploaded media is then governed by the KICKO service's account, storage, retention, and deletion rules. KICKO credentials are entered in the browser and are never shared with TrimOut.

## Other Network Actions

TrimOut accesses a remote address only when the user requests a network feature, such as downloading a video URL or connecting to KICKO. Local QR sharing exposes one selected file on the local network through a random, temporary address and stops automatically.

## Local Security

Connection session secrets are stored with operating-system encryption and are removed when the handoff completes, expires, or is cancelled. Signed upload URLs are used only for the active transfer and are not stored in project files. Logs are designed not to record passwords, access tokens, authorization headers, signed upload URLs, or full KICKO session secrets.

## Contact

Security reports can be sent to info@demente-show.com. Do not include passwords, access tokens, signed upload URLs, or private video files in a report.
